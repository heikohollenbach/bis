# 🌌 Überblick

## Vision

Ein persistentes Space-MMORPG mit Fokus auf:

- Kooperation (Crew & Gilden)
- Progression über Schiffe
- Wirtschaft & Kontrolle von Systemen

## Eckdaten

- Phasen: 4
- Dauer: ~18 Monate
- Services: 6
- Tech: C# / .NET / Unity

## 🎮 Gameplay

- Start als Shuttle
- Ressourcen sammeln
- Schiff erweitern
- Crew aufbauen

Explore → Mine → Build → Fight → Trade → Expand → Repeat

## 🌍 Welt

- Hierarchisch: Shuttle → Planet → System → Galaxie
- Prozedural generiert
- Zone-of-Interest System

## 🖥 Backend

- Autoritativer Server
- ASP.NET Core
- SignalR
- PostgreSQL
- Redis

## 🧱 Infrastruktur

- Docker Compose
- Traefik
- Raspberry Pi 5

## USP

- Spieler besitzt ein Schiff statt eines Charakter, das mit Fortschritt wächst
  - Ausbau in unterschideliche richtungen möglich (Kampf, Handel, Erkundung)
- Dynamische Wirtschaft & Politik durch Spielerinteraktionen
- Server läuft initial auf Raspberry Pi (Low-cost MMO)
